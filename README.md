# witwell-site

Public landing page for <https://witwell.ai>, served by GitHub Pages.

This repository is **public** because GitHub Pages requires a public repository on a free
plan. It contains the landing page and nothing else — no product code, no documentation,
no configuration. Witwell's actual source lives in the private repositories.

- `index.html` — the whole site, self-contained, no external dependencies or trackers
- `CNAME` — custom domain for GitHub Pages (`witwell.ai`)
